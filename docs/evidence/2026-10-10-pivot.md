# Pivot evidence — 2026-10-10

This record holds the evidence for the owner's decisions on 2026-10-10. The SRS and the stack cite it.

## Decisions

1. Melomae does not acquire audio. YouTube Music, yt-dlp, Deno, the stream-source interface, and the Bandcamp, SoundCloud, and SponsorBlock records are removed.
2. Melomae uses no online metadata service. MusicBrainz, the Cover Art Archive, and AcoustID are removed.
3. Melomae restores files that the user already owns. It keeps their tags, pictures, and folder tree.
4. The app stays free and local. A hosted backend is a later option (backlog B-012).
5. The client stays GPL-3.0-or-later. A future hosted backend stays closed source.

## MusicBrainz and AcoustID terms

Checked on 2026-10-10.

- MusicBrainz API (https://musicbrainz.org/doc/MusicBrainz_API): "Non-commercial use of this web service is free". Commercial users must "see our commercial plans or contact us".
- MetaBrainz account types (https://metabrainz.org/supporters/account-type): commercial means "a company with a current revenue stream or an expected revenue stream". A "pre-revenue start-up and expect to have revenue in the future" signs up as commercial. The Stealth Start-Up tier is "For start-ups that are in early stealth mode, and are not publicly offering their services." Bronze is "$100.00/month and up".
- MusicBrainz data (https://musicbrainz.org/doc/MusicBrainz_Database): tags "(including genre associations)", ratings, annotations, and search indexes are CC BY-NC-SA 3.0. Core data is CC0.
- AcoustID (https://acoustid.org/webservice): "This service is provided for free for non-commercial use only."

Conclusion: a planned paid service makes Melomae commercial under these terms. The free tiers would stop applying. The owner removed the services.

## Licensing of the open client and a closed backend

- GPLv3 §0 (`LICENSE:107-109`): "Mere interaction with a user through a computer network, with no transfer of a copy, is not conveying." A closed server does not convey the GPL client.
- Creative Commons (https://creativecommons.org/share-your-work/licensing-considerations/compatible-licenses/): "The GNU General Public License version 3 was declared a 'BY-SA–Compatible License' for version 4.0 on 8 October 2015." The page adds that "compatibility with the GPLv3 is one-way only."
- Inferred, not confirmed: running Apollo on a server does not Share the weights under CC BY-SA 4.0 §1. Whether restored audio is Adapted Material is not settled.
- Open point: outside contributions stay GPL. If the owner ever ships the server to customers, contributed code in it would force the GPL. A CLA or a server free of contributed code avoids this.

## Competitor check

### Neural Analog

Checked on 2026-10-10 by the owner, with a free account. Input: a 320 kb/s MP3 of a commercial track, tagged by MusicBrainz Picard, with a 1200×1200 front cover. Model: `universal_enhancer.1`, not Apollo. The audio is copyrighted and is not committed.

| Property | Input MP3 | Neural Analog FLAC |
|---|---|---|
| Duration | 262.6 s | 30.0 s (free-tier limit) |
| Format | MP3 320 kb/s, 44.1 kHz | FLAC 24-bit, 44.1 kHz |
| Text tags | 30 fields | 2 fields: title, artist |
| Picture | 1200×1200 JPEG, type "Cover (front)" | the same image, type "Other" |

Lost fields: album, album artist, track and total, disc and total, date, original date and year, genre, ISRC, barcode, catalog number, label, copyright, composer, lyricist, sort names, media, script, release type, status, and country, and six MusicBrainz IDs.

Measured with `ffprobe` and a numpy spectrum over the first 30 s. The input reached about 20.1 kHz. The output reached about 22.0 kHz.

Plan facts (https://neuralanalog.com/pro): Pro €29/month with 2,000 processing minutes. Max €49/month with 6,000. Extra minutes cost €20 per 1,000 down to €500 per 40,000. The free trial gives 6 processing minutes per month, runs models on 30 s of audio, and has no batch. Hobby and extra-minute tracks are "deleted after one week".

### MVSEP

Plan facts (https://mvsep.com/en/plans): free use allows 50 jobs a day, 10 min and 100 MB per file, and no batch. Registered users get 16-bit FLAC. Premium gets 24-bit FLAC. Credits cost 1 per audio minute, in packs from $0.05 down to $0.0091 per minute.

Checked on 2026-10-10 by the owner, with a free registered account. The upscaler sits under a page titled "Music & Voice Separation" and is chosen in a "Separation type" list. Model: "AudioSR (Super Resolution)", cutoff "Automatic". Output encoding: the default, MP3 320 kb/s. Input: a 320 kb/s MP3 of a commercial track from the same Picard-tagged album, with a 1200×1200 front cover. The audio is not committed.

| Property | Input MP3 | MVSEP output |
|---|---|---|
| Duration | 236.56 s | 236.57 s (full length) |
| Format | MP3 320 kb/s, 44.1 kHz | MP3 320 kb/s, 48 kHz |
| Text tags | 30 fields | none |
| Picture | 1200×1200 JPEG, type "Cover (front)" | none |
| File name | `01. The Fray - She Is (Album Version).mp3` | prefixed with a timestamp and an ID, lowercased, and suffixed with `_audiosr_mt_0_restored_mvsep.com` |

Measured with `ffprobe` and a numpy spectrum over the first 30 s. The input reached about 20.2 kHz. The output reached about 20.5 kHz. Inferred: the default lossy output removes most of the band that super-resolution adds. A FLAC output was not tested.

### What Melomae offers that these pages do not state

Local processing, free batch processing, 24-bit FLAC by default, tag and picture preservation, a mirrored folder tree, triage, volume-matched and blind compare, and provenance. "Not stated" does not prove that a competitor lacks a feature.
