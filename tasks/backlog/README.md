# Deferred backlog

This directory holds confirmed work that does not block the MVP.

Add one Markdown file for each deferred task. Use a `B-` identifier in the filename and in the task-board row. Record the evidence, the reason to defer, the dependencies, the acceptance criteria, and the condition that promotes the task to the MVP.

Do not place a defect that blocks an MVP user journey here. Put that task in `tasks/mvp`.
